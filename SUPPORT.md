# Support

OpenFieldPro is pre-1.0 software.

- Use GitHub Discussions for setup questions and community help once Discussions are enabled.
- Use GitHub Issues for reproducible defects and approved feature proposals.
- Use GitHub private vulnerability reporting for security concerns.
- Do not post credentials, customer records, private logs, signing material, or payment data.

Community support is best-effort. Paid support, if offered, is governed privately and does not change AGPL rights or access to the open-source core.
